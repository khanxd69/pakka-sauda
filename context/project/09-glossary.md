# 09: Glossary

| Term | Meaning |
|---|---|
| **Sauda** (سودا) | A deal. In the app, an accepted bid with frozen terms. *Pakka sauda* = a firm, settled deal. |
| **Mann / maund** (من) | 40 kg. Farmers think in mann; the database stores kg. |
| **Arhti / arthi** (آڑھتی) | Commission agent in the mandi. Often also lends to farmers against their crop. |
| **Mandi** (منڈی) | Wholesale produce market. |
| **Beopari** | Village trader who buys at the farm gate. |
| **AMIS** | Agriculture Marketing Information Service, Punjab: publishes daily wholesale prices (amis.pk). |
| **Grade-price ladder** | A bid's price per kg for grades A, B and C; null means "not accepted". |
| **Token** | A deposit the buyer pays after acceptance (10% of mid-range value). Simulated in the demo. |
| **Collection** | The buyer arrives, weighs and grades the crop, and loads it after the farmer agrees. |
| **Collection code** | A one-time 4-digit code shown on the farmer's phone that must appear in the buyer's photo (P1). |
| **Settled** | The farmer confirmed he received the balance. Only then does the fee count as revenue. |
| **Contract (code)** | A frozen type, signature or prop list that other workstreams depend on (`04-contracts.md`). |
| **Workstream A/B/C/D** | Backend and rules / Farmer app / Voice and media / Buyer, admin and pitch. |
| **P0 / P1 / P2** | Must ship for the demo / makes it convincing / only with spare hours. |
| **Checkpoint 1 / 2** | 1:45: list → bid → accept works on `main`. 3:30: the full deal including the dispute works on `main`. |
